# MemeDesk web app

Static home-screen dashboard for iPhone. Deploy this directory as an HTTPS website (for example, GitHub Pages), open it in Safari, tap Share → Add to Home Screen. Add up to eight tabs, enter any HTTPS URL or a search phrase, and reorder with arrows or dragging. Choose two small panels above a wide bottom panel, three equal panels, a large left or right panel, two panels, or a single panel. Settings are saved locally.

The Axiom and FOMO panels are best-effort iframes. Websites can prevent embedding with security headers or restrict sign-ins inside iframes; in that case tap OPEN to trade directly on the official site. J7Tracker's bookmarklet cannot be run across domains by this dashboard. No wallet credentials or private keys are collected.
